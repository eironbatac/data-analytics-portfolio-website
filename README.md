# Eiron Batac — Data Analytics Portfolio

## Project Overview

This repository contains my personal portfolio website, showcasing my background, technical skills, and data analytics projects. It serves as a central place to explore my work and learn more about my interests in data analytics.

## About Me

I am a Computer Science graduate with a Cum Laude distinction from Biliran Province State University. I am interested in data analytics, data visualization, and transforming raw data into meaningful insights.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Featured Projects

### 1. Retail Sales Performance Analysis
Analyzes retail sales data using SQL to explore sales performance across categories, subcategories, regions, shipping methods, and discount levels.

### 2. Customer Churn Analysis
Uses Python and Pandas to explore customer churn patterns and identify factors associated with customer retention.

### 3. HR Analytics — Employee Attrition Analysis
Explores employee attrition patterns and workplace factors using data analysis tools.

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
